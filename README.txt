The files currently use https://jatin-singer.pages.dev/ as the planned Cloudflare Pages URL.
If you choose a different Cloudflare project name, replace that URL in index.html, music/*/index.html,
robots.txt and sitemap.xml before submitting the site to Google.

Do not submit the sitemap to Google until the live URL is correct and the pages have been tested.
